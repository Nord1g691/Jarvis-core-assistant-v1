JARVIS Core Assistant

Interface vocale et visuelle avancée pour Home Assistant, conçue autour d’un assistant personnel nommé JARVIS.

Le projet combine une interface HUD futuriste, les commandes vocales, l’intégration Home Assistant, le suivi énergétique solaire, le contrôle du satellite vocal JARVIS sur iPhone, la synthèse vocale et le contrôle musical.

Fonctionnalités

* 🎙️ Commandes vocales JARVIS
* 🏠 Connexion à Home Assistant
* 📡 Communication avec Home Assistant via API et WebSocket
* ⚡ Suivi de la production solaire et de la consommation électrique
* 🔋 Calcul de l’autoconsommation solaire
* 🎤 Écoute et reconnaissance vocale
* 🤖 Réponse vocale de JARVIS
* 📱 Activation du satellite JARVIS sur iPhone
* 🎵 Lecteur musical intégré
* 🔊 Gestion du volume et réduction automatique de la musique pendant les échanges vocaux
* 💡 Interface HUD animée avec états visuels : écoute, réflexion et réponse
* 📟 Console système intégrée
* 📱 Interface optimisée pour smartphone, tablette et ordinateur

Architecture

L’interface fonctionne comme une couche visuelle et interactive au-dessus de Home Assistant. Home Assistant reste le moteur central pour les appareils, les automatisations et les services.

Le projet est conçu pour évoluer progressivement vers un véritable assistant personnel local connecté à l’environnement domotique.
