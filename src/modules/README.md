# JARVIS modules

Planned boundaries:

- `ui/` — V8 interface and presentation
- `voice/` — speech input/output
- `vision/` — camera and visual capabilities
- `home-assistant/` — Home Assistant communication
- `agents/` — agent orchestration and tools
- `config/` — application configuration

These are boundaries for future work, not a request to migrate the existing V8 code yet.
